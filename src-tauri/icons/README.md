# Icons Directory

Place your application icons here:
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (for macOS)
- icon.ico (for Windows)

For now, Tauri will use default icons if these are not present.
You can generate these using tools like:
- https://tauri.app/v1/guides/features/icons/
- or any icon generator online
